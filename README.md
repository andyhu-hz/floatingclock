# 浮动时钟 (Floating Clock)

一个简单的 Mac 桌面浮动时钟应用，显示24小时制时间，包含毫秒显示。

## 功能特点

- 24小时时间格式显示
- 毫秒级精确度
- 半透明背景
- 始终置顶显示
- 可拖动位置
- 双击关闭

## 安装要求

- Python 3.6 或更高版本
- PyQt6

## 安装步骤

1. 克隆或下载此仓库
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

运行以下命令启动时钟：
```bash
python floating_clock.py
```

## 操作说明

- 左键拖动：移动时钟位置
- 双击：关闭程序
